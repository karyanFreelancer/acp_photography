ACP Content V2 upgrade
1. Back up database and website first.
2. Import database/ACP_CONTENT_V2.sql in phpMyAdmin (non-destructive new table).
3. Open /ACP-Photography/admin/content-manager.php after admin login.
4. Add photos, films, brands, testimonials, services and pricing entries.
5. Homepage marquee shows published brands and testimonials. Films page shows published films.
6. Existing database and bookings are not deleted.
IMPORTANT: This is an incremental CMS upgrade. It does not replace every older management page. Verify in your local XAMPP installation.
